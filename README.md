# 🏦 MRN National Bank

### Operation Digital Vault

A single-file, console-based banking management simulation independently designed and developed using C.

---

## 📌 Project Overview

MRN National Bank is a console-based banking simulation that replicates basic banking operations through an interactive terminal interface.

The project was independently conceptualized, designed, and implemented from scratch using fundamental C programming concepts.

It features an interactive banking menu, account management options, transaction processing, authentication, and transaction statistics.

## ✨ Features

### 1. Account Overview

* View account holder information.
* Display account number and account type.
* Check current account balance.
* View the daily withdrawal limit.

### 2. Deposit Funds

* Deposit money into the account.
* Validate deposit amounts.
* Automatically update the account balance.
* Track total deposited amounts and successful deposit counts.

### 3. Withdraw Funds

* PIN-based authentication.
* Limited PIN verification attempts.
* Withdrawal amount validation.
* Balance and daily withdrawal limit management.
* Transaction tracking.

### 4. Money Transfer

* Enter a recipient account number.
* Prevent transfers to the same account.
* PIN-based authentication.
* Validate transfer amounts and available balance.
* Track total transferred amounts.

### 5. Transaction Statistics

* View total deposited amounts.
* View total withdrawn amounts.
* View total transferred amounts.
* Check successful transaction counts.
* Display current account balance.

### 6. Account Settings

* View the current daily withdrawal limit.
* Configure a new daily withdrawal limit.

### 7. Interactive Main Menu

* Navigate between banking services.
* Handle invalid menu selections.
* Exit the banking terminal.

## 🚀 How to Run

### Requirements

* Windows 11
* GCC compiler installed and accessible through the system PATH.
* A terminal such as Command Prompt or PowerShell.

### 1. Clone the Repository

```bash
git clone https://github.com/not-hypnosis/mrn-national-bank.git
```

### 2. Navigate to the Project Directory

```bash
cd mrn-national-bank
```

### 3. Compile the Source Code

```bash
gcc MRN_NATIONAL_BANK.c -o MRN_NATIONAL_BANK.exe
```

### 4. Run the Program

**PowerShell:**

```powershell
.\MRN_NATIONAL_BANK.exe
```

**Command Prompt:**

```cmd
MRN_NATIONAL_BANK.exe
```

Alternatively, open the source file in Visual Studio Code and compile and execute it using your configured C compiler.

## ⚠️ Important Disclaimer

MRN National Bank is an educational programming project and a simulated banking environment.

It is not intended for real financial transactions or actual banking operations.

Account information and authentication credentials are demonstration values hardcoded into the source code. Transaction data is maintained during program execution and is not permanently stored.
