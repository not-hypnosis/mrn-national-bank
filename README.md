# 🏦 MRN National Bank

### Operation Digital Vault

A console-based banking management simulation independently designed and developed using the C programming language.

---

## 📌 Project Overview

MRN National Bank is a console-based banking simulation developed to practice fundamental C programming concepts through a practical application.

The project was independently conceptualized, designed, and implemented from scratch as part of an ongoing C programming learning journey.

## ⚙️ Technologies Used

* **Programming Language:** C
* **Code Editor:** Visual Studio Code
* **Compiler:** GCC

## 🧠 Programming Concepts

The project demonstrates practical applications of:

* Variables and Data Types
* User Input and Output (`scanf`, `printf`)
* Conditional Statements (`if-else`)
* Switch Statements
* Looping Structures (`do-while`)
* Logical and Arithmetic Operators
* Control Flow and Decision Making
* Mixed-Concept Application

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/not-hypnosis/mrn-national-bank.git
```

### 2. Navigate to the Project Directory

```bash
cd mrn-national-bank
```

### 3. Compile the Source Code

```bash
gcc mrn_national_bank.c -o mrn_bank
```

### 4. Execute the Program

**Windows:**

```bash
mrn_bank.exe
```

**Linux/macOS:**

```bash
./mrn_bank
```
